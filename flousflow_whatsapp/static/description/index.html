Flous Flow WhatsApp

Presence-aware shared WhatsApp inbox for your team

A self-contained Odoo 19 Community suite that turns WhatsApp into a professional support & sales channel. Manage shared numbers, route conversations to the right agent, respect SLAs, hand off to CRM and send quotations & statements — all from one module.

Self-hosted Connector Setup

The companion connector runs on infrastructure controlled by the customer. On a Linux server with Docker Engine and Docker Compose v2, run: 

git clone --branch v1.4.0 --depth 1 https://github.com/FlousFlow/flousflow-whatsapp-connector.git
cd flousflow-whatsapp-connector
sudo ./deploy/install.sh --odoo-url https://odoo.example.com

The installer generates secrets, builds the pinned connector, creates a hardened systemd service and verifies its health. The Odoo addon never downloads or launches external code. New numbers register automatically; adding a number does not require editing Docker or restarting the connector.

Key Features

Shared Team Inbox

Real-time OWL inbox with live bus updates and a fallback poller. Every conversation is visible to the right team, with clear assignment states.

Smart Routing & SLA

Least-open + round-robin assignment, online/away/busy awareness and first-response / reply SLAs with breach tracking.

Safe by Design

Lease-based conversation locks, supervisor takeover, HMAC-signed connector webhooks, nonce replay protection and media validated by real file signatures.

Connect & Pair

  • Create a WhatsApp number and pair it with a QR code.
  • Live status: draft → QR → connecting → connected.
  • Multi-company safe numbers, teams and direct allow/deny rules.
  • Agent / Supervisor / Administrator / Executive Odoo 19 privileges.

Run Your Business

  • CRM handoff — create leads from conversations with safe partner resolution.
  • Sales bridge — send quotation PDFs from the inbox or the sale order.
  • Accounting bridge — send customer/vendor statements as PDFs.
  • HR awareness — operational availability of agents.
  • Voice notes — record, preview and send native WhatsApp PTT audio.
  • Audio files — upload supported audio without converting it to a voice note.

Technical Highlights

  • Depends only on Odoo core modules: base, mail, bus, contacts, crm, hr, sale, account, web.
  • Connector API: HMAC-SHA256 signed webhooks with a 5-minute timestamp window and one-time nonces stored in the database.
  • Outbox claiming, delivery/read receipts, stale-message timeout with retry.
  • Serialized outbound sending, configurable pacing and a customer-service window policy.
  • Connector heartbeat/version monitoring and supervisor manual retry.
  • Media policy inspects WebM/MP4 magic bytes — disguised video is blocked.
  • Idempotent inbound/outbound handling (duplicate-safe) and echo de-duplication.

Requirements

Odoo 19 (Community or Enterprise). This module requires a companion QR-based WhatsApp connector service (not included) that calls the signed HTTP API. To protect your number from service interruptions, deploy tested connector releases, persist one session per number and configure outbound pacing.

The companion connector uses unofficial QR-paired WhatsApp Web technology. It is not the Meta WhatsApp Cloud API and cannot guarantee against account restrictions. Do not use it for unsolicited bulk messaging; customers remain responsible for consent and compliance with applicable terms and law.
